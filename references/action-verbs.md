# Action Verbs: Weak → Strong

Use this as a quick lookup when rewriting bullets. The point isn't to use rare words, it's to replace passive/vague verbs with ones that signal ownership and outcome.

## The "delete and replace" list

| Replace this | With one of these |
|---|---|
| Worked on | Built, Developed, Shipped, Designed, Implemented |
| Helped with | Contributed to, Supported, Partnered on (only if you were genuinely supporting) |
| Was responsible for | Owned, Led, Managed, Drove |
| Assisted in | Contributed to, Supported, Co-authored |
| Participated in | Contributed to, Joined |
| Involved in | (delete, usually empty) |
| Used [tech] | Built [thing] using [tech], Implemented [thing] in [tech] |
| Did [task] | (specify the action: Designed / Built / Wrote / Reviewed / etc.) |

### Solving

## Rules of thumb

- **Don't repeat the same verb 5 times in one section.** Vary it.
- **Match verb to seniority.** "Led a team of 8" is fine for a senior; for a junior IC it's an overclaim. Don't recommend a verb stronger than the role warrants.
- **Don't go thesaurus-fancy.** "Spearheaded" is fine once on a CV; don't use it three times. "Built" is honest and clear.
- **The verb is not the work.** A strong verb on a weak claim ("Spearheaded reading documentation") is worse than a plain verb on a real claim ("Built a parser for our config format").
